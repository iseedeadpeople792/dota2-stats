# Dota 2 Статистика

Окно с данными OpenDota и помощником пиков. Вкладки:

- **Статистика** — профиль, ранг, винрейт, герои, последние матчи с разбором.
- **Динамика** — форма за 10/20/50/100 игр, скользящий винрейт и KDA, разрезы по ролям, стороне, времени суток и дням.
- **Добивание** — твой темп добивания против эталонов OpenDota по героям (перцентили) и разбор по минутам (5/10/15-я).
- **Пики** — подбор героя против выбранных врагов: поправка на твой ранг, «почему», «лучше не брать», популярные предметы.
  В приложении есть кнопка **«Определить героев с экрана»** (верхняя панель Dota 2).
- **⚙ Настройки** — свой API-ключ OpenDota, очистка кэша, запуск/остановка помощника добивания и его допущения.

## Запуск
- `Dota2Stats.exe` — готовое приложение. Для помощника добивания рядом должна лежать папка `..\dota-lasthit`.
- `run_dev.bat` — из исходников. `build.bat` — собрать .exe заново.

## Проверки
```
node --test tests/core.test.js tests/api.test.js tests/pickcore.test.js tests/trendcore.test.js
..\dota-lasthit\.venv\Scripts\python.exe -m pytest tests/test_bridge.py
node tests/e2e/smoke.cjs        # живой браузер + OpenDota
node tests/e2e/bridge.cjs       # интерфейс моста с подставным Python
node tests/e2e/real_app.cjs     # настоящее окно, мост и помощник (APP_EXE=путь к .exe — проверить сборку)
```

## Устройство
`web/core.js, api.js, pickcore.js, trendcore.js` — логика без интерфейса (тестируется в node).
`web/*.js` остальное — вкладки. `bridge.py` — связь страницы с помощником добивания через `python -m lasthit.cli` и `status.json`.
Оригинальные файлы до переработки: `_backup/`.

## Ограничения
- Данные OpenDota: матчи игрока доступны, только если включено «Открыть публичные данные матчей». Бесплатный лимит ~60 запросов/мин — помогает кэш и свой ключ.
- Эталоны добивания — за весь матч, все ранги вместе: это ориентир, а не норма.
- Определение героев с экрана проверено на искусственных слотах (117 из 127 героев узнаны, ни одной подмены) и на вашем герое в реальной игре. Вражеский драфт в настоящем матче ещё не проверялся.
